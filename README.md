# Bits

Bits is a Scrap Mechanic mod experiment for adding logic and maths components. The repository contains the mod metadata, Lua scripts, GUI layouts and icon resources.

One example is the interactive counter component: it accepts logic connections, stores its value and provides an in-game editing interface.

## Project contents

- `Scripts/Interactive` contains interactive components.
- `Scripts/Shared` and `Scripts/Bootstrap` contain shared helpers and startup code.
- `Gui` contains the mod's interface layouts and icon map.

This is a game-specific mod project; its scripts expect Scrap Mechanic's Lua API and mod environment.
